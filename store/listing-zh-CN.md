# 简体中文商店文案

名称：Nivra 下载管理器

摘要：管理下载、自动归档，并记录速度曲线与连接信息。

网站：https://hibrielle.github.io/nivra/

支持：https://github.com/Hibrielle/nivra/issues

隐私政策：https://hibrielle.github.io/nivra/privacy.html#chinese

## 详细介绍

照常下载，文件自动放好。

Nivra 把下载管理和自动归档放在一起。用工具栏弹窗看进度，打开完整管理页查找文件，再用规则决定新下载该存到哪里。

• 下载管理：暂停、继续、取消、重试、复制链接和定位文件，也支持搜索、多选和备注。能否续传由 Chrome 和下载服务器共同决定。

• 自动分类：默认提供 15 类文件、343 种扩展名，也可以自己配置规则。按文件类型、月份或日期组合分类，调整目录顺序，保存前能看到实际路径示例。支持网站、关键词、MIME、正则与命名模板。

• 批量下载：粘贴链接或编号范围，扫描选中网页的链接、图片和音视频资源，控制下载并发。按需捕获所选标签页后续出现的网络资源；定时任务需要浏览器保持运行。

• 下载报告：查看实际采样的速度曲线、暂停和中断事件，以及 Chrome 观测到的连接 IP。报告保存在本机；短下载可能没有足够采样，连接 IP 也可能属于 CDN 或代理。

• 按你的习惯使用：支持深浅模式，以及跟随浏览器或手动选择中英文。规则可导入导出，也可手动备份到 Chrome 同步。绑定自己的 qBittorrent、Transmission 或 aria2 后，可以从种子任务菜单发送已下载的种子文件。

Nivra 只整理新下载，保存目录位于 Chrome 的下载根目录之内，不移动已有文件。不提供多线程加速、流媒体分片合并或受保护内容处理。打开文件使用浏览器默认方式；删除本地文件需要确认，插件无法撤销。

隐私方面，没有广告、分析 SDK 或开发者运营的数据收集服务器。为关联下载连接信息，插件会短暂观察 HTTP(S) 请求元数据；网页扫描与资源捕获只针对你选中的页面。下载记录和报告留在本机，规则只有手动备份时才进入 Chrome 同步；下载器凭据和种子文件只发给你配置的服务。数据类型、保留时间及删除方式见隐私政策。
