## Detailed description

Nivra is a Chrome download manager with automatic file organization and batch downloading.

Check progress from the toolbar, find downloaded files in one place, and set rules to save new downloads into the right folders.

• Manage your downloads
Pause, resume, retry, or cancel tasks. Search your download history, copy links, and open a file or its folder.

• Keep files organized
Sort new downloads by file type, website, month, or day. Use the built-in rules or create your own, and preview the save path before applying a rule.

• Download several files at once
Paste a list of links or choose from resources found on a webpage. Queue downloads and choose how many run at a time.

• View download details
See download speed over time and connection details, including endpoint IPs when Chrome provides them.

Also includes light and dark themes, English and Simplified Chinese, and rule import/export. You can optionally connect your own qBittorrent, Transmission, or aria2 service to receive torrent files.
