## Detailed description

Keep your downloads organized without changing how you download.

Nivra brings a compact progress popup, a full download manager, and automatic folder rules together. Download from a website as usual; Nivra can put new files into the right subfolders and help you find them afterward.

• Manage downloads: pause, resume when the server supports it, cancel, retry, copy links, and show files in their folders. Search tasks, add notes, and select several downloads at once.

• Organize automatically: use 15 default categories covering 343 file extensions, or write your own rules. Combine file types with monthly or daily folders, choose their order, and preview the resulting path before saving. Conditions include extensions, websites, keywords, MIME types, and regular expressions.

• Download in batches: paste links or numbered URL ranges, find resources on selected pages, and control queue concurrency. Optional network capture discovers later resources from the tabs you select. Scheduled tasks require Chrome to be running.

• Look back at a download: inspect sampled speed charts, pauses, interruptions, and connection endpoint IPs observed by Chrome. Reports stay on your device. Very short downloads may have too few samples, and an observed IP may belong to a CDN or proxy rather than the origin server.

• Make it yours: English and Simplified Chinese follow your browser, with a manual language choice in settings. Use light or dark mode, import and export rules, or manually back up rules through Chrome Sync. You can also connect your own qBittorrent, Transmission, or aria2 service and send completed torrent files from the task menu.

Nivra only organizes new downloads inside Chrome's download root. It does not move existing files, bypass protected content, merge streaming segments, or provide multithreaded acceleration. File opening uses Chrome's default behavior. Local file deletion always requires confirmation and cannot be undone by Nivra.

Privacy: there are no ads, analytics SDKs, or developer-operated data collection servers. To associate connection details with downloads, Nivra briefly observes HTTP(S) request metadata. Resource scanning and capture apply to pages you select. Download records and reports stay local; rules enter Chrome Sync only when you request a backup. External downloader credentials and torrent files are sent only to the service you configure. See the privacy policy for data types, retention, and controls.

Free, open-source software under the MIT license. Requires Chrome 127 or later.
