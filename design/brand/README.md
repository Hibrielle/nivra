# Nivra

选定名称：Nivra。短、柔和、易读，不附加中文释义，也不把产品功能写进名字。

选定图形：黑色圆角方形中的路径与箭头，末端用低饱和的小圆点收尾。图标与名称可独立使用，沿用现有界面的文字尺寸。界面仍以中性色为主，品牌色不替代下载成功、失败等状态色。

矢量原稿：`../../icons/brand.svg`。安装资源：`icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`。运行 `npm run build:icons` 可通过 Playwright 从矢量原稿重建 PNG；按开发环境需要设置 `CHROME_EXECUTABLE`。

名称、扩展清单、界面标题、右键菜单、规则包标识、MCP 工具及发行 ZIP 统一使用 Nivra / nivra。本轮不保留旧名称的兼容别名。
