让 AI 帮我写规则

描述你的需求，复制提示词给 AI，再把返回的 JSON 粘贴到下方。提示词只包含你填写的需求和配置格式。

MCP 配置助手

源码仓库提供本地 MCP，支持规则格式、模板、校验、试跑和配置包生成。在仓库运行 npm run mcp:config 获取客户端配置。结果仍需在此预览后导入。

支持 Nivra 配置包、RegExp 原生规则 JSON 和 Chrono 规则数组。保留现有规则，跳过内容相同的规则；支持最大 128 KiB 的配置文件。

下载之后，一切有序

1

按平时的方式下载

插件只处理启用后的新下载，不扫描或移动已有文件。

2

按规则决定保存目录

在 Chrome 的默认下载目录中创建子目录。若开启“下载前询问保存位置”，浏览器仍可能弹出保存对话框。

3

从这里找到实际文件

只有下载完成且实际目录符合规则，才显示“已归档”。手动另存为或其他下载插件可能改变目标位置。

规则和最近 500 条记录保存在本机；可手动备份规则到浏览器同步存储。记录不保存来源网址的查询参数。待下载队列和当前资源列表会保留下载所需的完整链接。
